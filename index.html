เชื่อมต่อคลาวด์ (Google ชีต)

ยังไม่ได้เชื่อมต่อ
รองรับ 2 แบบ — Supabase (แนะนำ ไม่ต้องดูแล Script) หรือ Google ชีต (Apps Script)
ดูวิธีตั้งค่าแต่ละแบบ
• Supabase — ไปที่ เชื่อมต่อSupabase_ขั้นตอนติดตั้ง.md คัดลอก URL + API key (บรรทัดละอย่าง) แล้วใส่ในช่องด้านล่าง
• Google ชีต — ไปที่ เชื่อมต่อGoogleชีต_ขั้นตอนติดตั้ง.md (Deploy Web App แบบ "Anyone")
Supabase (แนะนำ) — เก็บในฐานข้อมูลคลาวด์ฟรี ไม่ต้องจัดการ Script อีกเลย เปิดจากเครื่องไหนก็เห็นข้อมูลเดียวกัน
Google ชีต — เก็บใน Google ชีตผ่าน Apps Script เวลาแก้ Script ต้อง redeploy ครั้งใหม่
